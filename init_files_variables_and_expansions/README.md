# init_files_variables_and_expansions

- 0-alias: creates an alias named ls with the value rm -f *.
- 1-hello_you: prints hello user, where user is the current Linux user.
- 2-path: adds /action to the end of the PATH.
- 3-paths: counts the number of directories in the PATH.
- 4-global_variables: lists the environment variables.
- 5-local_variables: lists all local variables, environment variables and functions.
- 6-create_local_variable: creates a new local variable named BEST with the value School.
- 7-create_global_variable: creates a new global variable named BEST with the value School.
- 8-true_knowledge: prints the result of the addition of 128 with the value stored in the environment variable TRUEKNOWLEDGE.
- 9-divide_and_rule: prints the result of POWER divided by DIVIDE.
- 10-love_exponent_breath: displays the result of BREATH to the power LOVE.
- 11-binary_to_decimal: converts the number in base 2 stored in the environment variable BINARY to base 10.
- 12-combinations: prints all possible combinations of two lowercase letters, one per line and in alphabetical order, except oo.
- 13-print_float: prints the number stored in the environment variable NUM with two decimal places.
- 14-decimal_to_hexadecimal: converts the number in base 10 stored in the environment variable DECIMAL to base 16.
- Task 15 blog post, What Happens When You Type ls *.c and Press Enter: https://www.linkedin.com/pulse/what-happens-when-you-type-ls-c-press-enter-brian-cruz-tcvke
- 15-rot13: encodes and decodes text using the rot13 encryption, reading from the standard input.
- 16-odd: prints every other line from the standard input, starting with the first line.
- 17-water_and_stir: adds the numbers stored in WATER (base water) and STIR (base stir.) and prints the result in base bestchol.
